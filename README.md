# The Digital Detective

A hands-on assignment to explore computer systems, practise Terminal and Git, build a small Python number converter, and learn how computers communicate.

## Topics

Computer fundamentals, Terminal, operating systems, programs, number representation, Git and GitHub, and networking.

## Run the number converter

From the repository root:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
