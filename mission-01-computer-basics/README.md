# Mission 1 — Know Your Computer

## 1. Task / objective

Explain how a computer takes input, processes it, produces output and stores information. Identify examples of hardware, software and computer-based systems.

## 2. Work completed

### Task 1.1 — IPOS example: sending a message in a chat

| Stage | What happens | Hardware or component |
|---|---|---|
| Input | A message is typed or pasted into the chat and sent. | Keyboard and laptop |
| Processing | The chat app handles the message. The computer's processor runs the app, and RAM holds information it is using. The message also travels over the network to the service. | CPU, RAM and network connection |
| Output | The reply is shown in the chat window. | Display |
| Storage | The conversation remains available in the chat history so it can be opened again. | Storage used by the chat service |

This example follows a message from entering it to seeing and revisiting the reply.

## 4. My understanding

IPOS is a useful way to describe what happens during a computer task. Input is the information a person provides, processing is the work done by the computer, output is the result shown to the person, and storage keeps information for later. Hardware is the physical equipment; software is the set of programs and instructions that make the equipment useful.
